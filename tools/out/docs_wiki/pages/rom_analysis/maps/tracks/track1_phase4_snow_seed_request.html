Closed Read

  • the user boundary is correct: without real driving or a preserved later savestate, the current autonomous menu-entry lane is not a credible path to the phase-4 snow corridor
  • the bounded menu probes did still close one useful low-level detail:
  • right in the early menu corridor samples as state_0960 = 0x0100
  • down in the early menu corridor samples as state_0960 = 0x0400
  • this matches the already known right+down = 0x0500 pulse from the no-opponent corridor
  • but those same probes do not close a usable snow route:
  • early 01:BAB3 right pulses never move selector_1c7c off 0 and do not even preserve the normal gameplay handoff
  • early 01:BAB3 down pulses still keep selector_1c7c = 0 all the way into the ordinary 02:9016 Desert Blast corridor
  • a later be43+1-6:down guess without the earlier organic selector steps does not even reach 01:BE43; it stalls in the 01:C1D2 family instead
  • practical reading:
  • the current menu automation is still useful for early/default gameplay and for front-end narrowing
  • it is not yet a trustworthy way to reach phase 4 snow before a game-over boundary
